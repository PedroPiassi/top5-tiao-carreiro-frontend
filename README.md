# Como rodar o frontend

### Passo a passo

Clone Repositório

```sh
git clone https://github.com/PedroPiassi/top5-tiao-carreiro-frontend.git
```

Abra a pasta que você clonou o projeto.

Suba o container do projeto

```sh
docker-compose up -d
```

Crie o Arquivo .env

```sh
cp .env.example .env
```
